Installer sur ChromeOS

MyTube fonctionne sur ChromeOS via l'environnement Linux (Crostini).

1

Activer Linux

Ouvrez Paramètres → Avancés → Développeurs → Environnement de développement Linux et cliquez sur Activer.

2

Télécharger MyTube

Téléchargez le fichier .deb ou .AppImage depuis les boutons ci-dessus.

3

Installer

Option DEB : Double-cliquez sur le fichier .deb ou lancez sudo dpkg -i MyTube_*.deb dans le terminal Linux.

Option AppImage : Rendez-le exécutable avec chmod +x MyTube-*.AppImage puis lancez-le.

4

C'est prêt !

MyTube apparaît dans votre lanceur d'applications. Les fichiers téléchargés seront accessibles directement dans l'app Fichiers de ChromeOS.
